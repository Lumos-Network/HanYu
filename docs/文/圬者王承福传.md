## 《圬者王承福传》

**圬之为技，贱且劳者也。有业之，其色若自得者。听其言，约而尽。**

**问之，王其姓，承福其名。世为京兆长安农夫。天宝之乱，发人为兵。持弓矢十三年，有官勋，弃之来归。丧其土田，手镘衣食，余三十年。舍于市之主人，而归其屋食之当焉。视时屋食之贵贱，而上下其圬之佣以偿之；有余，则以与道路之废疾饿者焉。**

**又曰：“粟，稼而生者也；若布与帛，必蚕绩而后成者也；其他所以养生之具，皆待人力而后完也；吾皆赖之。然人不可遍为，宜乎各致其能以相生也。故君者，理我所以生者也；而百官者，承君之化者也。任有大小，惟其所能，若器皿焉。食焉而怠其事，必有天殃，故吾不敢一日舍镘以嬉。夫镘易能，可力焉，又诚有功；取其直虽劳无愧，吾心安焉。夫力易强而有功也；心难强而有智也。用力者使于人，用心者使人，亦其宜也。吾特择其易为而无愧者取焉。**

**“嘻！吾操镘以入富贵之家有年矣。有一至者焉，又往过之，则为墟矣；有再至、三至者焉，而往过之，则为墟矣。问之其邻，或曰：噫！刑戮也。或曰：身既死，而其子孙不能有也。或曰：死而归之官也。吾以是观之，非所谓食焉怠其事而得天殃者邪？非强心以智而不足，不择其才之称否而冒之者邪？非多行可愧，知其不可而强为之者邪！将富贵难守，薄功而厚飨之者邪！抑丰悴有时，一去一来而不可常者邪！吾之心悯焉，是故择其力之可能者行焉。乐富贵而悲贫贱，我岂异于人哉？”**

**又曰：“功大者，其所以自奉也博。妻与子，皆养于我者也。吾能薄而功小，不有之可也。又吾所谓劳力者，若立吾家而力不足，则心又劳也。一身而二任焉，虽圣者不可能也。”**

**愈始闻而惑之，又从而思之，盖贤者也。盖所谓独善其身者也。然吾有讥焉，谓其自为也过多，其为人也过少，其学杨朱之道者邪？杨之道，不肯拔我一毛而利天下。而夫人以有家为劳心，不肯一动其心，以畜其妻子，其肯劳其心以为人乎哉！虽然，其贤于世之患不得之而患失之者，以济其生之欲，贪邪而亡道，以丧其身者，其亦远矣！又其言有可以警余者，故余为之传而自鉴焉。**



#### 背景

此文作于公元801年贞元十七年，韩愈三十四岁，在京任国子博士。“圬杇污”不同偏旁的这三个“wu”，指三种职业，分别是泥瓦匠，木匠，管道工，此文所写的王承福就是一个泥瓦匠。在大唐有战功的人可以获得官勋，官职加勋爵，王承福大概拿的是最低一级的官勋，陪戎副尉武骑尉。据推断王承福在安史之乱中被招纳进入军队，在平叛过程中立下军功，获得官勋，在军中待了13年，后主动放弃官勋，回家种田。王承福在军队的这13年，是大唐最混乱的时候，杀伐的残酷是常人不能理解的，这也是王承福主动退出的主要原因。他回到家乡后田土尽失，只能在长安城中务工，做了个泥瓦匠，租住在有钱人家中，以工钱偿付租金和伙食费，剩下的收入，他全部拿去救济残疾军人，流浪汉，这就是王承福的事迹。



#### 概述

王承福很厉害，韩愈采访他时约略已经年过花甲，在大唐能活过60岁的人凤毛麟角，他经历的是大唐最混乱的时期，一生风雨，打了十三年仗，立了功得了功勋，重要的是他有人生观，价值观，“食焉而怠其事，必有天殃”这不是一般人会说的话，这也正是韩愈为其写传的根本。

韩愈是文以载道的，通过一问一答的形式，表达了韩愈心中正确的社会价值是什么样，社会价值体系其背后是社会伦理体系，社会伦理决定社会法理，社会法理决定了社会治理，有时候可以自上而下，有时候必须自下而上。重大的社会革命其都以文化运动为起点，就是这个道理。



#### 解读

**“圬”是一种技术门槛较低的普通劳动工作。他以此为业，看他的样子，好像还很满足。听他说话，简约详尽，有概括问题的能力。**

**他回答我说：姓王，名承福。世代在京都长安郊区种田。天宝年间爆发安史之乱，被征召入伍。在军中一直做弓箭手一共十三年，获得了官勋，后来主动放弃回到家乡。结果发现土地都没了，只能在京城做个劳工，一干就是三十年。租住在别人家中，白天出去工作，晚上回来在这住，在这吃饭。我要看屋主提供的食宿水平，再决定我务工收费的标准；如果有剩余，就施舍给路边的残疾人或流浪汉。**安史之乱京城一度被攻陷，后唐军收复京城，其土地经历了再分配，此时王承福还在军中任职，所以土地流失了。他在京城务工，收费标准按照食宿水平上下波动，不多要，而且也不积累财富，有多的钱全散了，这人是个“傻子”吗？可以看出他有原则，有想法，而且自己决定自己的劳动定价，有着独特的人生观和价值观。

**他又说：粮食要耕种才能收获；布匹要养蚕纺织才能制作；这世上所有维持生计的东西，都需要靠人的劳动才能拥有；这是所有人都必须依赖的**。马克思在《资本论》中开篇讲社会分工，王承福是懂经济学的，劳动是创造价值的根源。**但一个人不能什么都做，所以大家各自分工，互相维持生计。所以一国君主要做的事，就是通过治理建立良好的社会秩序，让这样的分工有序进行，人民相生相养；百官要做的，就是帮助君王实现具体事宜。一个人的职责有大有小，只看一个人的能力，如同各类器皿，发挥不同作用。在其位却怠其事，必遭天谴，所以我不敢不尽职尽责。做泥瓦工是容易的，靠一把力气就可以了，但实实在在的有成果，拿这份工钱固然辛苦，但内心无愧，过的安稳。我可以出体力做出成效，但没有智慧难以从事脑力劳动。体力劳动这受别人领导干活，脑力劳动者领导别人干活，这也是符合常理的。我只是挑选对我来说简单的，无愧于心的事来做。**领导与被领导，是地位差异，阶级差异，财富差异的合理来源吗？不是的！这只是不同的社会分工而已，但现实这样的关系，确实导致了社会地位，阶级和财富差异。换句话说，既然合理的各司其职，带来了不合理的地位分化，那么谁还会安心的各司其职呢？如果大家都不会安心的各司其职，那么这个国家，这个社会会怎么样呢？

**哎！我拿着工具在富贵人家做工好些年了。有些人家我第二次去已经成废墟了，有的人家第三次，第四次去，发现已经成废墟了。向邻居询问，有的回答说：”哎！触犯刑法被杀了！“有的回答说：”被杀了后，子孙没有能力继承。“还有的回答说：”是死后，官府没收了他的家产。“在我看来，不会是在其位却怠其事，遭了天谴吧！不会是没有与之匹配的才智，以投机取巧的方式获得了与自己能力不匹配的位置了吧！不会是做了很多亏心事，强行获取了不属于自己的东西了吧！不会是你这富贵本就难以守住，以微薄的功劳享有这丰厚的报酬吧！又或者盛衰自有定数，来去无常，无法长久！我为他们感到惋惜，所以告诫自己只选择有能力做好的事来做！我喜欢富贵，也讨厌贫贱，我也是个普通人！**这就是王承福的价值观和人生观，他能在乱世活那么久有他的道理，这不仅仅是经济学伦理，更是自然伦理。

**他又说：能力大的人，能获取更多的物资来供养自己。妻子儿女，都要靠他养活。我能力小，所以没有妻儿也是合情合理的。我只是一个提供体力的劳工，没有那个能力成家，而且心累，身心俱疲。一身二任，就算圣人来了也不行**！

**我刚开始有些疑惑，又思考了一会儿，觉得他真是一个大贤者。这真是一个可以独善其身的人。但我讥讽他说，他为自己考虑的太多，为别人考虑的太少，他难道是学杨朱之道的吗？杨朱的主张，是一毛不拔的，只有自己，没有天下。这个人把成家视为劳心的负担，连养活妻儿都不肯费心，难道还肯为别人劳心出力吗？即便如此，这个不在乎得到而害怕失去的人是比世上的普通人要贤明的，那些贪攻冒名以致身死的那些人，与他相比那就差的太远了！他说的这些话有可以警醒我的地方，所以我为他作此传，用以自鉴。**

哎！很难不与现实相联系，历史与现实，无二无别，我国的生育率创下新低，结婚率创下新低，心理疾病越来越普遍。中国人民是那么的善良，那么的勤劳，但换来了什么？父母怎么可能希望自己的孩子和自己一样，到这人间来吃苦呢？很多学者，认为这是一种自私，怎能不让人愤概！强迫人民掏空六个钱包供楼，疯了吗？最后一段韩愈真的如一般的学者那样不食人间烟火，真的认为这是一种自私？韩愈是以普通学者的口吻在反讽。1300年过去了，这个世界还是这个样子。

于人，亡道而丧其身；于国，失道而国破家亡，那个所谓的盛世不过昙花一现，毫无意义。大唐不过80年就走向衰败，而后就是中华名族历史最黑暗的五代十国，李隆基，李林甫，杨国忠，真应该被钉在历史的耻辱柱上。
